# Tigil Reports

AI-powered business report generation for Ethiopian companies.

## Stack

- **Framework:** Next.js 16 (Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 + shadcn/ui
- **Auth & Database:** Supabase
- **Payments:** Chapa
- **AI:** DeepSeek (via internal API)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment

Copy `.env.local.example` to `.env.local` and fill in your Supabase and Chapa keys.

## Build

```bash
npm run build
```

## Deploy

Deploy to any Node.js host (Vercel recommended).
